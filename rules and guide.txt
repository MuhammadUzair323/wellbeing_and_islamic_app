=====================================================
FOCUS SHIELD PROJECT - COLLABORATION & SETUP GUIDE
=====================================================

--- STEP 1: ONE-TIME MACHINE SETUP (DO THIS ONCE) ---

1. Complete everything listed in "PREREQUISITES.txt":
   - Install VS Code with Flutter, Dart, and Cline extensions.
   - Extract Flutter SDK into C:\src\flutter and add C:\src\flutter\bin to PATH.
   - Install Android Studio and command-line tools.

2. Accept the GitHub Invitation:
   - Check your email or open:
     https://github.com/MuhammadUzair323/wellbeing_and_islamic_app/invitations
   - Click "Accept invitation".

3. Clone the Project to Your Laptop:
   - Open Git Bash or PowerShell on your Desktop and run:
     git clone https://github.com/MuhammadUzair323/wellbeing_and_islamic_app.git
     cd wellbeing_and_islamic_app
     code .

4. Verify Flutter Dependencies:
   - Inside the VS Code terminal (Ctrl + ~), run:
     flutter pub get
     flutter run -d chrome

-----------------------------------------------------
